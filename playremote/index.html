常見問題

什麼是 Play! Remote 的「飛鼠功能」？

飛鼠功能讓智慧電視遙控器變成滑鼠，可在螢幕上自由移動游標，提供更直覺、靈活的操作體驗，適合電視瀏覽器、遊戲操作、應用程式控制

如何開啟飛鼠模式？

  • 按下 遙控器上的「飛鼠鍵」
  • 使用 遙控器移動游標，即可像電腦滑鼠一樣操作

Play! Remote 贈送的 tv.SOGA APP 是什麼？如何安裝？

✅ tv.SOGA APP 是專為 Android 智慧電視設計的 AI 語音搜尋瀏覽器，可快速搜尋影片、網站資訊，並支援 QR Code 掃描

安裝方式：

📥 Google Play 商店下載

  1. 在 Android TV 或 Google TV 上開啟 Google Play 商店
  2. 搜尋 tv.SOGA APP
  3. 點選下載與安裝
  4. 安裝完成後，開啟 APP 即可開始使用

📥 APK 下載（適用於無 Google Play 商店的設備）

  1. 進入官網 tv.SOGA APP下載頁
  2. 點選下載 APK
  3. 下載後，開啟 Android 電視盒的「檔案管理」進行安裝
  4. 安裝完成後，開啟 APP 即可開始使用

如何輸入序號？

  1. 新會員 → 註冊時輸入序號
  2. 已註冊但在試用期內 → 進入「我的設定 > 帳戶 > 試用帳戶」綁定序號
  3. 試用期結束 → 啟動 tv.SOGA APP，系統會自動彈出「輸入序號」框

為什麼 Play! Remote 連接 USB 後無法使用？

請先確保遙控器已正確配對至 USB（Dongle）

解決方法：

  1. 打開遙控器背蓋，找到 2.4G / 藍牙切換鍵
  2. 切換到「2.4G 模式」（綠燈閃爍）
  3. 同時長按「返回鍵 + 語音鍵」
  4. 確認 USB（Dongle）上的藍燈亮起，表示配對成功

為什麼 Play! Remote 記憶鍵（學習鍵）無法配對？

記憶鍵（學習鍵）僅適用於紅外線（IR）遙控器，無法配對藍牙設備

如何進行 IR 遙控器配對？

  1. 長按要設定的記憶鍵（約 3 秒）直到紅燈亮起
  2. 對準舊遙控器的發射端
  3. 按住舊遙控器上的按鈕（1~3 秒）
  4. 當紅燈閃爍後，配對成功！

Play! Remote 滾輪功能支援左右滑動嗎？

目前滾輪功能僅支援上下滑動，無法左右滑動，搭配 tv.SOGA APP 可更順暢地瀏覽網頁內容

為什麼 Play! Remote 語音鍵無法使用？

部分非 Android TV（AOSP）系統可能會阻擋 USB 語音功能

解決方案：

  1. 改用藍牙模式連接遙控器
  2. 如果問題持續，請確認您的電視盒品牌與型號
  3. 部分品牌會阻擋非原廠遙控器的語音功能

Play! Remote 為何只能關閉電視，無法開啟？

部分電視在關閉（休眠模式）時，會自動關閉 USB 或藍牙連線，導致無法開機

解決方法：

  • 使用「記憶鍵（學習鍵）」學習原廠遙控器的開關機功能
  • 確保電視或電視盒處於完全關機狀態後，進行記憶鍵配對
  • 配對完成後，即可自由開關電視與電視盒

Play! Remote 在 2.4G 模式下無法使用記憶鍵（學習鍵），該如何解決？

如果 2.4G 模式下無法使用學習鍵，請先嘗試以下步驟：

解決方案：

  1. 拔除 USB Dongle
  2. 切換至紅外線（IR）模式
  3. 重新進行學習鍵配對

為什麼 Play! Remote 語音無法輸入，完全讀不到聲音？

部分電視盒/電視的原廠遙控器已內建語音功能，可能會阻擋 USB 連接的語音模式

解決方案：

    1. 使用藍牙模式（避免 USB 阻礙語音功能）
    2. 確認電視盒品牌與型號
    3. 如果問題持續，請提供遙控器與電視的操作影片，聯絡官方LINE客服: @tvsoga進行技術支援
